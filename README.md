# Поляна

Сайт независимого художественного объединения «Поляна». Первая реализованная страница посвящена произведению **Light** Анны Гончаровой.

**[Страница работы художника](https://wayavg.github.io/polyana/)**

## О проекте

Страница знакомит посетителя с произведением, художницей и выставкой NON-PLACES. Включает изображения, сведения о работе и интерактивную форму запроса об условиях приобретения.

**Макеты в Figma:** [страница Light](https://www.figma.com/design/9t88kJ39MreXS0Flst0pGC/поляна?node-id=348-1254) · [форма запроса](https://www.figma.com/design/9t88kJ39MreXS0Flst0pGC/поляна?node-id=357-89) · [расширенное состояние формы](https://www.figma.com/design/9t88kJ39MreXS0Flst0pGC/поляна?node-id=357-198).

## Интерактивная форма

**Задача:** помочь посетителю уточнить условия приобретения выбранного произведения.

При нажатии «Уточнить приобретение» открывается форма с названием, автором, изображением и стоимостью работы. Пользователь может выбрать цель приобретения: для себя, в подарок, для пространства или другую. В зависимости от выбора появляются дополнительные поля. Имя и контакт обязательны; при незаполненных полях показываются ошибки. После корректного заполнения отображается экран подтверждения.

Форма реализована как переиспользуемый React-компонент `O_PurchaseDialog`. Данные произведения передаются через **props**, а значения полей, выбранные варианты и ошибки управляются через **useState** и **onChange**.

**Отправка демонстрационная:** данные не передаются на сервер. Стоимость 37 000 ₽ взята из макета и не подтверждает наличие произведения.

## Технологии и запуск

React 19, JavaScript/JSX, CSS, Webpack 5, Yarn.

Требуются Node.js 20+ и Yarn Classic 1.22.x.

```bash
yarn install
yarn start
```

Локально сайт открывается по адресу `http://localhost:3000`. Для production-сборки:

```bash
yarn build
```

Webpack создаёт папку `docs/`, которая публикуется на GitHub Pages с помощью GitHub Actions.

## Структура компонентов

Проект организован по принципам **Atomic Design**:

- `src/javascripts/atoms/A_*` — базовые элементы;
- `src/javascripts/molecules/M_*` — составные элементы;
- `src/javascripts/organisms/O_*` — блоки интерфейса и интерактивная форма;
- `src/javascripts/pages/P_ArtworkPage.jsx` — композиция страницы;
- `src/stylesheets/tokens.css` — общие параметры дизайн-системы.
