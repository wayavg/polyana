# Поляна

Сайт независимого художественного объединения «Поляна». Стек: Webpack 5, React 19, JavaScript/JSX, CSS, PostCSS.

Исходная учебная основа: [new-static-site-boilerplate](https://github.com/annkomkova/new-static-site-boilerplate), лицензия MIT сохранена.

## T03 — Light (Анна Гончарова)

Первая реализация утверждённого [макета Figma](https://www.figma.com/design/9t88kJ39MreXS0Flst0pGC/поляна?node-id=348-1254). Десктопное полотно 1440 px, поля 64 px, асимметрия исходной композиции, изображение произведения, текст, выставка, другие работы, навигация, футер и архивная стоимость.

Выставка NON-PLACES прошла 24 января — 7 февраля 2026 года. Цена Light 37 000 ₽ взята из архивного макета: наличие и условия покупки НЕ подтверждены.

## PurchaseDialog — учебный интерактивный компонент

[Базовая Figma-форма](https://www.figma.com/design/9t88kJ39MreXS0Flst0pGC/поляна?node-id=357-89) · [расширенное состояние](https://www.figma.com/design/9t88kJ39MreXS0Flst0pGC/поляна?node-id=357-198)

Пользователь нажимает «Уточнить приобретение», видит изображение и сведения о выбранной работе, выбирает цель (для себя / в подарок / для пространства / другое). Для пространства показываются дополнительные варианты (ресторан / офис / отель / другое), пожелания по размещению. Город и контекстные поля необязательны; имя и контакт обязательны. При пустых полях появляется ошибка, а после корректного ввода — итоговое состояние. Есть кнопки «Пример заполнения», «Закрыть», обработка Escape.

Это **один переиспользуемый компонент** на React state с данными artwork через props. Финальная отправка демонстрационная: никакие введённые данные никуда не передаются.

## Запуск

Требуется Node.js 20+.

    npm install
    npm start

Production-сборка:

    npm run build

Webpack создаёт папку docs/. GitHub Actions собирает docs/ и публикует её в GitHub Pages. В Settings → Pages выберите источник публикации **GitHub Actions**. Действующий адрес страницы будет доступен после успешного выполнения deploy.

## Структура Atomic Design

- src/javascripts/atoms/A_* — типографика, кнопки, ссылки, поля, подписи и разделители
- src/javascripts/molecules/M_* — составные метаданные, подписи и элементы формы
- src/javascripts/organisms/O_* — Header, Footer, ArtworkHero, ArtworkGallery, PurchasePanel, PurchaseDialog, MainNavigation
- src/javascripts/pages/P_ArtworkPage.jsx — композиция T03
- src/javascripts/data/artworks.js — источник данных для нескольких произведений
- src/stylesheets/tokens.css — шрифты, цвет, размеры, сетка
- src/stylesheets/artwork.css — композиция страницы 1440 px
- src/stylesheets/dialog.css — формы и навигация

## Изображения / шрифты

Оригинальные файлы изображений из Figma уже сохранены в src/assets/images/ и версионируются в git. Это исключает временные URL из браузерной версии. При недоступности импортируемых ассетов сборка будет заблокирована до добавления этих файлов. Шрифты Geologica Medium и Golos Text загружаются из Google Fonts.

## Ограничения этого этапа

Адаптивная версия ещё не разрабатывалась. Точное визуальное совпадение с Figma на 1440px требует браузерной сверки и возможных коррекций. Прочие страницы, переходы между ними и реальная отправка запросов не реализованы. Навигационные названия остальных разделов показаны, но сознательно не ведут на отсутствующие страницы.

## Использование ИИ

ИИ использовался для чтения структуры Figma, перевода макета в React/Atomic Design, выделения токенов и верстки, программирования состояний и валидации формы, настройки Webpack/CI. Результат необходимо самостоятельно проверить и понимать перед учебным просмотром. Принцип работы useState, props, JSX, обработки событий и сборки Webpack можно объяснить на исходниках.
