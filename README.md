# Поляна

Сайт независимого художественного объединения «Поляна».

## Техническая основа

- Webpack 5: development и production сборки
- React 19 + JavaScript/JSX
- HTML, CSS, PostCSS, Autoprefixer
- Многостраничный режим через HtmlWebpackPlugin
- GitHub Pages из папки `docs` через Actions

Основа адаптирована из [new-static-site-boilerplate](https://github.com/annkomkova/new-static-site-boilerplate) (MIT); исходная лицензия в `LICENSE`.

## Запуск локально

Требуются Node.js 20+ и npm.

```bash
npm install
npm start
```

Открыть http://localhost:3000

Сборка для публикации:

```bash
npm run build
```

Webpack создаёт папку `docs/`. Для воспроизводимых установок после первого `npm install` следует закоммитить `package-lock.json`; далее использовать `npm ci`.

## Структура

- `config/` — dev/prod Webpack и регистрация HTML-страниц
- `src/index.html` — HTML-оболочка
- `src/javascripts/index.jsx` — точка входа React
- `src/javascripts/components/App.jsx` — стартовый компонент
- `src/stylesheets/` — CSS (пока только reset и временный layout)
- `.github/workflows/deploy.yml` — сборка и размещение GitHub Pages

Текущий экран — только временный заголовок. Демонстрационные страницы исходного шаблона и старые файлы шрифтов удалены. Реальные разделы, ассеты и дизайн-токены переносим из утверждённых макетов Figma, без импровизированных страниц.

## Публикация

В GitHub откройте **Settings → Pages → Build and deployment → Source → GitHub Actions**. Workflow срабатывает при push в `main`, запускает `npm run build`, загружает `docs` и публикует сайт.

Сборка в GitHub Actions ещё должна быть проверена; статус смотрите на вкладке Actions.

## Интерактивный компонент для учебного задания

Запланирована реализация согласованной в Figma интерактивной формы запроса на приобретение произведения: переключение вариантов, условные поля, проверка значений, итоговое состояние. Пока код компонента не перенесён из утверждённого прототипа.

Перед сдачей сюда будут добавлены:
- Назначение компонента и пользовательский сценарий
- Ссылка на конкретный Figma-прототип
- Ссылка на работающий опубликованный экран
- Описание React-компонентов, состояний и проверок
- Прозрачная информация об использовании нейросетей (для каких задач и почему)

## Безопасность

На статическом сайте нет авторизации пользователей, серверных сессий и секретных ключей. GitHub Actions использует временный токен с правами на деплой. Пароли и персональные API-токены нельзя хранить в клиентском JavaScript.
